QtWebEngine / Chromium
-----------------------
Nexo Solar embeds the operative dashboard (Mockup/) using QtWebEngine
(QWebEngineView), used from modbuspython/ui/web_dashboard.py and
modbuspython/ui/map_widget.py. QtWebEngine ships as part of the
PySide6-Addons wheel and bundles a build of the Chromium engine.
- QtWebEngine is supplied by PySide6-Addons, whose installed metadata
  declares the alternatives listed above. Per-file/module license texts
  and the Chromium attribution inventory must be retained from the exact
  QtWebEngine source/build used for the release.
- Chromium includes many independently licensed third-party components.
  The installed PySide6-Addons metadata is NOT their license inventory.
  Exact-version Chromium notices remain a release prerequisite; the
  upstream attribution reference to consult is:
  https://doc.qt.io/qt-6/qtwebengine-index.html#licenses-and-attributions
- The QtWebEngine sandbox helper process (QtWebEngineProcess) ships as a
  separate executable inside the PySide6 wheel
  (PySide6/Qt/libexec/QtWebEngineProcess on Linux); it is redistributed
  as a separate replaceable file in the onedir packaging described below.

Why this matters for how Nexo Solar is packaged
-------------------------------------------------
The LGPL-3.0 requires that a user of the combined work be able to relink or
replace the LGPL-licensed library (here, Qt/PySide6/QtWebEngine) with a
modified or different compatible version. To honor that:

- Nexo Solar is packaged in PyInstaller "onedir" mode (NOT "onefile"), so
  the Qt/PySide6/QtWebEngine shared libraries (including
  QtWebEngineProcess and the Chromium resource/locale files it needs)
  ship as separate, individually replaceable files next to the
  application executable, instead of being embedded inside a single
  opaque binary.
- To replace the bundled libraries: close Nexo Solar and its helper
  processes, back up the installation, and unpack/build a compatible set
  of PySide6, PySide6-Essentials, PySide6-Addons and shiboken6 for the same
  OS, architecture and CPython ABI as the packaged application. Replace
  the binding extension modules AND their Qt shared libraries/plugins,
  QtWebEngineProcess, resources and locales as a coherent set. Preserve
  the bundle's relative layout, normally under _internal/PySide6 and
  _internal/shiboken6 (inspect the actual release payload first).
  Linux RPM installs under /opt/nexo-solar; Windows uses the install
  directory selected by the installer. Replacing protected installation
  files requires appropriate filesystem permissions. Do not replace the
  application executable or user data. Start the application and run the
  documented installed-product smoke test; restore the backup if the
  replacement is incompatible. Compatibility and replacement have not yet
  been demonstrated against a released binary.
- Nexo Solar's own application code is proprietary and is distributed only
  in compiled/frozen form; only the Qt/PySide6/QtWebEngine libraries
  themselves are LGPL-licensed and only those are relinkable under this
  notice. Nexo Solar's own source availability and usage terms are defined
  separately in NEXO_SOLAR_LICENSE.txt (mirrors the repository's
  LICENSE.txt) and are not altered or extended by this notice.

terceros con sus propias licencias y avisos de atribucion. Los paquetes PySide6
distribuidos en PyPI (PySide6, PySide6-Essentials, PySide6-Addons, shiboken6
6.11.2) NO incluyen esos avisos: solo declaran la licencia del binding en sus
metadatos. Verificado el 2026-09-23 inspeccionando los .dist-info instalados.

Estado (actualizado 2026-09-23): el inventario correspondiente a la version
exacta de QtWebEngine que viaja en este paquete (6.11.2, Chromium
140.0.7339.225) esta documentado en
licenses/QTWEBENGINE_THIRD_PARTY.txt, con las 126 componentes que la propia
documentacion de Qt lista para QtWebEngine, sus identificadores de licencia,
los enlaces oficiales a doc.qt.io para cada uno, y el texto base de las
familias de licencia (MIT, BSD-2-Clause, BSD-3-Clause, Apache-2.0, ISC, Zlib)
que cubren la mayoria de esos componentes, obtenido de SPDX License List Data.

NO es una garantia de cumplimiento legal completo; es un inventario trazable
